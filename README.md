# Karista Creative Experience — Erchomai Theater

An independent single-page animated prototype for **Erchomai: How the Persistence of God Produces Endurance in Us** by Karista Williams.

## Experience

Scroll to the stage once. A 9-second timed animation takes over: painted theater scenery, rolling water, an invitation hand, a path through the water, a cardboard-set transition, and the book reveal. The animation is **not tied to individual scroll frames**, avoiding the jerky movement seen in the previous prototype. Use **Replay Scene** or **Skip Intro** to control the experience.

The images in `assets/` are transparent PNG cutouts, optimized for the web. The book cover is a WebP image. The site uses plain HTML, CSS, and JavaScript with no build process or external libraries.

## Deployment

On GitHub, configure **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**. Open the published URL in Safari or another browser to test.

This project is separate from `8math-wordwall-draft1`.
